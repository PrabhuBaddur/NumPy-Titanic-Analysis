# Titanic Dataset Analysis with NumPy

Analysed the Titanic dataset using only NumPy to answer 5 key questions.

## Key Findings
- Average age of passengers: 29.7 years
- Survival rate: 38.4%
- Average fare paid: $32.20
- Oldest passenger: 80 yrs | Youngest: 0.4 yrs
- Class 1: 216 | Class 2: 184 | Class 3: 491 passengers

## Tech Used
- Python 3.12
- NumPy 1.26.4
